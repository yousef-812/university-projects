# ❌⭕ مشروع الذكاء الاصطناعي: لعبة X-O وتحليل ODESDA & PEAS

مشروع جامعي متكامل يطبق مفاهيم الذكاء الاصطناعي (**PEAS Framework** و **ODESDA Framework**) ومحرك اتخاذ القرار **Minimax Algorithm**.

---

## 📌 محتويات المشروع
* **`Self_Driving_Car_ODESDA_PEAS.pptx`**: العرض التقديمي للمشروع ولتحليل السيارة ذاتية القيادة وأطر العمل.
* **`index.html` / `style.css` / `script.js`**: واجهة تطبيق ويب تفاعلية فائقة الجودة بتصميم متألق باللونين الأخضر والأصفر مع شاشة تفكير الـ AI ومؤثرات حركية (SVG Line & Confetti).
* **`xo_game.py`**: تطبيق سطح المكتب بلغة بايثون بـ Tkinter مع شاشة محاكاة التفكير المباشرة لـ Minimax.

---

## 🛠️ الأطر والخصائص العلمية (PEAS & ODESDA)
1. **Performance Measure (مقياس الأداء):** الفوز (+10)، منع المنافس، وفرض التعادل (0) بأقل خطوات.
2. **Environment (البيئة):** شبكة $3\times3$ مكشوفة بالكامل (Fully Observable).
3. **Actuators (المشغلات):** تنفيذ النقلة وتحديث الواجهة وإعلان النتيجة.
4. **Sensors (المستشعرات):** دالة فحص الخانات الشاغرة واكتشاف الفوز/التعادل.

## 🚀 كيفية التشغيل

### 1️⃣ تشغيل تطبيق الويب (Web App)
فتح ملف `index.html` مباشر في أي متصفح، أو عبر تشغيل خادم محلي:
```bash
python -m http.server 8080
```
ثم الدخول على `http://localhost:8080`

### 2️⃣ تشغيل تطبيق بايثون (Desktop App)
```bash
python xo_game.py
```
